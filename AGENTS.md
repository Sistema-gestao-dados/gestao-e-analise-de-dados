# Gestão e Análise de Dados

Sistema corporativo de gestão e análise operacional de transporte, com
módulos de conversão de arquivos (BI Cittati, Relatório de Viagens e
Passagem Trecho) integrados ao mesmo painel.

Stack: TanStack Start (React 19) + Supabase (auth e banco) + Vite + Nitro.
Sem vínculo com nenhuma plataforma de builder — roda em qualquer host que
suporte Node/Nitro (recomendado: Vercel).

Veja `DEPLOY.md` para o passo a passo de publicação.
